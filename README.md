# Amazon EKS patterns

This repo contains various design patterns used in talks and enablement sessions. Please see folders for individual patterns.

It is assumed that commands are executed from a macOS or Linux-based OS.

## Prerequisites

- AWS account with [AWS CLI](https://docs.aws.amazon.com/cli/latest/userguide/getting-started-install.html) configured
- [eksctl](https://eksctl.io/installation/)
- [kubectl](https://kubernetes.io/docs/tasks/tools/)
- [Helm](https://helm.sh/docs/intro/install/)
- [Flux CLI](https://fluxcd.io/flux/installation/)
- A container runtime: [Colima](https://github.com/abiosoft/colima) (recommended for macOS), [Podman](https://podman.io/), or [Docker](https://docs.docker.com/engine/install/)
- GitHub account and [personal access token](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/managing-your-personal-access-tokens)
